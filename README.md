# Abstract
This website allows users to record their menstrual dates and track their moods simultaneously. It provides a simple way for users to keep track of their menstrual cycles while documenting their emotional states over time.

# Features
1. Menstrual Date Tracking: Users can record the dates of their menstrual periods.
2. Mood Rating: Users can assign a mood rating to each recorded date to document their emotional state.
3. Record Review: Users can view their previous records and track their menstrual history and mood changes over time.

# Method
Fronend: React
Backend: Flask

# Activattion
## Follow these steps to set up and run the backend.
```bash
cd backend
python -m venv venv
pip install -r requirements.txt
python app.py
```
## Follow these steps to set up and run the frontend.
```bash
cd frontend
npm install
npm run dev
```
